# Local startup and Ollama

Run `npm run dev` from the repository root to start both API and website. On Windows, `./Start-Jatayu.ps1` starts missing services in hidden background windows and leaves them running. Its defaults are API 5001 and website 3001; optional parameters are ApiPort and WebPort. Logs are under `.runtime/`. Starting only the frontend leaves weather, warnings and chat unavailable.

Ollama must be running locally. The website uses server-side `POST /api/chat` with the installed `llama3.1:8b` model, not OpenRouter. Optional server environment variables: `OLLAMA_MODEL` (default `llama3.1:8b`) and `OLLAMA_BASE_URL` (default `http://127.0.0.1:11434`, local loopback hosts only). No API key is needed for this local service. No model is downloaded automatically. First response can take longer while the model loads; requests have a 90-second timeout.

The assistant is limited to weather, disaster preparedness, basic emergency help, facility discovery, safer travel and JATAYU usage. Explicit unrelated/instruction-override requests are blocked before inference; the local model must additionally classify all other requests as in-scope before its answer is shown. Model-based enforcement is not a formal guarantee against every adversarial prompt. User system messages are rejected. Numerical current weather is independently fetched by the server, not trusted from browser-supplied telemetry. Missing information stays unavailable; no warnings, bed availability or dispatch are invented. Chat has no facility-control or dispatch tools.

Official IMD empty feeds are distinguished from unavailable feeds; cached feeds show a cached label and timestamp. Weather is Open-Meteo model-derived current data, not a local station measurement. All 265 interface translation keys are provided in Telugu; place names, source metadata and some legacy specialist panel strings remain in their original language. Weather, emergency directory and other data-source responses retain their original wording. Local Llama multilingual wording may be less fluent than the static interface translations.
